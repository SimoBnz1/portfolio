# Portfolio Web Developer - Mohamed Ben Izza 🚀

Un portfolio moderne, réactif et hautement performant développé avec **React.js**, **Tailwind CSS** et **Vite**. Conçu selon une approche rigoureuse de **Spec-Driven Development** (SDD) pour présenter mes compétences, mes projets et mes coordonnées professionnelles.

---

## 🎨 Aperçu & Thème

- **Design:** Dark Modern / Futuristic Glassmorphism
- **Palette de couleurs:** Noir Deep (`#0B0F17`), Slate (`#0F172A`), Accents Violet/Indigo Neon (`#A855F7`, `#6366F1`)
- **Responsive:** Mobile-first, adapté à toutes les tailles d'écrans.

---

## 🛠️ Stack Technique

- **Front-End Framework:** React.js (Vite)
- **Styling & CSS:** Tailwind CSS (v3 / v4)
- **Icons:** SVG / Lucide Icons
- **Déploiement recommandé:** Vercel / Netlify

## 🚀 Installation & Démarrage

### 1. Cloner le projet
```bash
git clone https://github.com/SimoBnz1/portfolio.git
cd portfolio
```

### 2. Installer les dépendances
```bash
npm install
```

### 3. Lancer le serveur de développement
```bash
npm run dev
```

L'application sera accessible sur `http://localhost:5173/`.

### 4. Build pour la production
```bash
npm run build
```
